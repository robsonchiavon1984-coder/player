  1. No Google Cloud Console, abra APIs e serviços › Credenciais e edite o seu ID de cliente do tipo Aplicativo da Web (pode ser o mesmo que você já usa).
  2. Em Origens JavaScript autorizadas, acrescente exatamente este endereço:
  3. Confirme que a Google Drive API está ativada no projeto.
  4. Cole abaixo o ID de cliente (termina em .apps.googleusercontent.com).

Para não repetir este passo em cada aparelho, grave o ID no arquivo config.js antes de publicar (veja o README).
